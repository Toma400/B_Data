# Baedoor Data
Baedoor Data is data repository for [From Steam and Magic](https://baedoor.github.io/projects/fsam.html)
Morrowind mod and future [Baedoor (3D)](https://baedoor.github.io/projects/_games/b3d.html)
game.

### Contributing
Anyone can contribute an asset, requesting claims found on [browser](https://baedoor.github.io/files/claims/bdata/list.html).
Make sure to read the [terms and requirements](https://baedoor.github.io/wcontr/_guidelines.html) 
before you submit anything, however.
